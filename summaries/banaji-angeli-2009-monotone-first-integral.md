# Banaji & Angeli (2009) — Convergence in Strongly Monotone Systems with an Increasing First Integral

Proves every bounded orbit converges for strongly monotone semiflows with a $K$-increasing conserved first integral, with unique equilibrium per level set.

## Main Result

**Theorem 2.4**: For a strongly monotone semiflow on a convex cone $Y$ with a first integral $H$ satisfying $\nabla H \in \operatorname{int}(K^*)$, each level set $S(0,h)$ has a unique equilibrium that attracts all orbits on that level set. Generalizes earlier work by Mierczyński.

## Applicability to OA System

The OA system does **not** directly satisfy the hypotheses: the Lyapunov-like functional $\Psi$ is increasing (not conserved), so there is no conserved first integral. However, the **ideas** — level-set analysis combined with monotonicity — may transfer to the cooperative OA setting. See [[kuramoto-stability-problem]] for the target application.
